# Training datasets

The current working dataset is **[synthetic_hinglish_8000](synthetic_hinglish_8000)**.
It contains 8,000 training, 1,000 validation and 1,000 synthetic test phrases.
Use its `all_splits.csv` as trainer input so the fixed partitions are retained.

Read [the dataset guide](../README.md) for file roles, provenance and limitations.
Keep revised datasets in a new versioned folder rather than overwriting the
examples and audit used for a completed experiment.
